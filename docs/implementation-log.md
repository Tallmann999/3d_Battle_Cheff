Editor **6000.2.14f1** найден по csproj: `D:\Program-All\Unity_hub_launcher\Unity_programm\6000.2.14f1\Editor\Unity.exe`. Первый sandbox-запуск остановился на timeout licensing до компиляции. Компиляция и generation/validator прошли. Исправлены обнаруженные несовпадение имени параметра AddAction установленного Input System и закрытие последней открытой generated-сцены перед сохранением. Исправление регенерации подтверждено отдельным тестом.

- **EditMode: 5/5 PASS**, 0 failures. Общая pause/speed, FIFO вложенных событий/отписка, изоляция ошибок view handler, dispose старой попытки, повтор Builder с неизменностью working-файла и GUID конфига/input.
- **Play Mode: 3/3 PASS**, 0 failures. Pause/resume/restart и сохранность definitions; движение настоящими Input System событиями, мышь, Escape и UI Submit→Resume; occlusion raycast, E-фокус и RMB-возврат.
- Синтетические устройства в batch-тестах используют временную копию InputSettings с разрешённым фоновым вводом; исходные настройки восстанавливаются. Проверка движения направлена от столешницы, чтобы не путать ввод с корректным столкновением.
- Реальная отрисовка URP/HUD сохранена PNG; кириллица читается. Проверен весь русский алфавит встроенного LegacyRuntime.ttf.
