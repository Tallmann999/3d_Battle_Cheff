# Feature Index — канонический индекс

Обновлено: 2026-10-08. Полный GDD: [GAME_CONCEPT.md](../GAME_CONCEPT.md). Решения: [decisions.md](decisions.md). Аудит: [audit.md](audit.md). Другого изменяемого индекса нет.

Статусы: proposed → specified → ready → in_progress → implemented → verified; blocked/deferred сопровождаются причиной. Здесь specified означает наличие карточки поведения, а не окончательного баланса или кода. ready означает, что можно начать ближайшую работу без нового дизайн-выбора. implemented — написано; verified — нужный сценарий фактически проверен в Unity/сборке, с доказательством в логе.

Все фичи относятся к premium-проекту (D-006); базовые механики применимы при любой модели распространения. Автор — владелец дизайна/приёмки, Codex — документация и реализация. Наличие технических пакетов шаблона не завершает F-001.
